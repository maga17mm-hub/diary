# Diary — Личный Дневник & Планировщик Задач 📓⚡

Современное веб-приложение (PWA), оптимизированное для iOS и мобильных устройств, в фирменном дизайне системы Raycast / TradeLog.

---

## 🌟 Основные разделы приложения

### 1. Вкладка «Мысли» (Дневник в стиле Google Keep & Obsidian)
- **Свободный поток мыслей**: мгновенная фиксация идей, инсайтов, рефлексии и выводов.
- **Закрепление записей (Pin to top)**: важные мысли всегда сверху в отдельном блоке с золотым индикатором.
- **Теги и фильтрация**: интерактивная лента тегов (`#Идеи`, `#Рефлексия`, `#Инсайты`, `#Личное`, `#Планы`) и мгновенный поиск.
- **Markdown-форматирование**: жирный шрифт, курсив, списки задач с чекбоксами, цитаты и код.
- **Эмоции и фокус**: выбор маркера настроения (💡, 💭, ⚡, 🧘, 🔥, 🎯).
- **Режим чтения**: чистое окно для погружения в длинные заметки.

### 2. Вкладка «Задачи» (Планировщик в стиле Todoist)
- **Горизонты планирования**: быстрое переключение между режимами:
  - **Сегодня**: фокус на текущих делах дня.
  - **Неделя**: задачи на ближайшие 7 дней.
  - **Все**: полный список активных задач.
  - **Готово**: история завершённых дел.
- **Шкала прогресса дня**: наглядная визуализация выполненных задач за сегодня (`X из Y (Z%)`).
- **Быстрое добавление**: строка ввода с созданием задачи по нажатию Enter.
- **Уровни приоритета (P1 – P4)**:
  - 🔴 **P1**: Срочно (высокий приоритет)
  - 🟡 **P2**: Важно
  - 🔵 **P3**: Обычный
  - ⚪ **P4**: Базовый
- **Интерактивные чекбоксы**: тактильный отклик и анимация завершения.

### 3. Вкладка «Настройки»
- **7 цветовых тем оформления** из приложения Trades:
  - `Raycast Midnight` (Тёмная с неоновым кораллом)
  - `Paper · Светлая` (Тёплая кремовая бумага)
  - `Cyberpunk Neon` (Киберпанк с циан-акцентом)
  - `Emerald Forest` (Глубокий изумрудный)
  - `Nordic Slate` (Северная грифельная палитра)
  - `OLED Pure Black` (Глубокий чёрный для OLED-экранов)
  - `Warm Amber` (Тёплый янтарный уют)
- **Очистить кэш и применить обновления**: специальная кнопка для сброса кэша Service Worker и мгновенного применения свежей версии без выхода или переустановки PWA.
- **Резервное копирование**: экспорт всех записей и задач в JSON и восстановление из файла.
- **Демо-режим**: возможность в один клик загрузить примеры записей для знакомства.

## 📱 Установка на iPhone (iOS PWA)

1. Откройте сайт приложения в **Safari** на iPhone.
2. Нажмите кнопку **«Поделиться»** (иконка квадрата со стрелкой вверх внизу экрана).
3. Прокрутите вниз и выберите **«На экран "Домой"»** (Add to Home Screen).
4. Нажмите **«Добавить»**. Приложение появится на рабочем столе как нативное iOS-приложение без рамок браузера.

## 🛠 Технологии

- **Vanilla HTML5, CSS3, ES6+ JavaScript**: максимальная скорость и нулевые зависимости.
- **IndexedDB**: надёжное локальное хранение данных на устройстве без ограничений localStorage.
- **Service Worker & PWA Manifest**: автономная работа даже без доступа к интернету.
- **Safe Area Insets**: идеальная посадка на экранах с Dynamic Island и «чёлкой».
