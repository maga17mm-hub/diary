# Мысли Заремки — Личный Дневник & Планировщик Задач 📓💖

Современное веб-приложение (PWA), оптимизированное для iOS и компьютера, в фирменном дизайне Raycast / TradeLog.

> **Приложение посвящено самой невероятной девушке на свете ❤️**

---

## 🌟 Основные возможности

### 1. Вкладка «Мысли» (Дневник в стиле Google Keep & Obsidian)
- **Свободный поток мыслей**: мгновенная фиксация идей, инсайтов, рефлексии и выводов.
- **Закрепление записей (Pin to top)**: важные мысли всегда сверху в отдельном блоке с золотым индикатором.
- **Теги и фильтрация**: интерактивная лента тегов (`#Все`, `#Идеи`, `#Рефлексия`, `#Инсайты`, `#Личное`, `#Планы`) и мгновенный поиск.
- **Markdown-форматирование**: жирный шрифт, курсив, списки задач с чекбоксами, цитаты и код.
- **Эмоции и фокус**: выбор маркера настроения (💡, 💭, ⚡, 🧘, 🔥, 🎯, ✨).
- **Режим чтения**: чистое окно для погружения в длинные заметки.

### 2. Вкладка «Задачи» (Планировщик в стиле Todoist)
- **Горизонты планирования**: быстрое переключение между режимами:
  - **Сегодня**: фокус на текущих делах дня.
  - **Неделя**: задачи на ближайшие 7 дней.
  - **Все**: полный список активных задач.
  - **Готово**: история завершённых дел.
- **Шкала прогресса дня**: наглядная визуализация выполненных задач за сегодня (`X из Y (Z%)`).
- **Быстрое добавление**: строка ввода с созданием задачи по нажатию Enter.
- **Уровни приоритета (P1 – P4)**:
  - 🔴 **P1**: Срочно (высокий приоритет)
  - 🟡 **P2**: Важно
  - 🔵 **P3**: Обычный
  - ⚪ **P4**: Базовый
- **Интерактивные чекбоксы**: тактильный отклик и анимация завершения.

### 3. Аккаунт и Синхронизация (Телефон <-> Компьютер)
- Создание аккаунта прямо в приложении.
- **Код синхронизации (Sync Key)**: уникальный защищённый ключ, позволяющий войти в свой аккаунт на компьютере или планшете.
- **Двусторонняя облачная синхронизация**: любые мысли и задачи, записанные на телефоне, мгновенно становятся доступны на компьютере и наоборот.
- Автономная работа: если нет интернета, данные сохраняются локально в IndexedDB и синхронизируются при появлении сети.

### 4. Вкладка «Настройки»
- **7 цветовых тем оформления** из приложения Trades:
  - `Raycast Midnight` (Тёмная с неоновым кораллом)
  - `Paper · Светлая` (Тёплая кремовая бумага)
  - `Cyberpunk Neon` (Киберпанк с циан-акцентом)
  - `Emerald Forest` (Глубокий изумрудный)
  - `Nordic Slate` (Северная грифельная палитра)
  - `OLED Pure Black` (Глубокий чёрный для OLED-экранов)
  - `Warm Amber` (Тёплый янтарный уют)
- **Очистить кэш и применить обновления**: специальная кнопка для сброса кэша Service Worker и мгновенного применения свежей версии без выхода или переустановки PWA.
- **Резервное копирование**: экспорт всех записей и задач в JSON и восстановление из файла.
- **Особенное послание**: кнопка для повторного открытия экрана с посвящением для Заремки.

## 💻 Адаптация под компьютер (Desktop Station)

Приложение автоматически определяет большой экран компьютера и оптимизирует интерфейс:
- **Верхняя навигация вместо нижней панели**: нижняя мобильная панель скрывается, а вкладки («Мысли», «Задачи», «Настройки») переносятся в аккуратный верхний командный бар.
- **Широкоэкранный 3-колоночный обзор**: заметки и мысли располагаются в удобной сетке в 3 колонки.
- **2-колоночный рабочий стол задач**: фильтры и шкала прогресса дня закреплены в левой боковой панели, а список задач и строка быстрого ввода — справа.
- **Фирменные тёмные скроллбары** и подсветка элементов при наведении курсора.

### ⌨️ Горячие клавиши (Keyboard Shortcuts)
| Клавиши | Действие |
|---|---|
| `Alt` + `1` | Переключиться на вкладку «Мысли» |
| `Alt` + `2` | Переключиться на вкладку «Задачи» |
| `Alt` + `3` | Переключиться на вкладку «Настройки» |
| `Alt` + `N` | Создать новую мысль или задачу |
| `/` | Сфокусироваться на строке поиска или быстрого ввода |
| `Ctrl` + `Enter` (или `Cmd` + `Enter`) | Быстро сохранить запись в окне |
| `Escape` | Закрыть любое открытое модальное окно |
| `?` | Открыть справку по горячим клавишам |

## 📱 Установка на iPhone (iOS PWA)

1. Откройте сайт приложения в **Safari** на iPhone: [https://maga17mm-hub.github.io/diary/](https://maga17mm-hub.github.io/diary/)
2. Нажмите кнопку **«Поделиться»** (иконка квадрата со стрелкой вверх внизу экрана).
3. Прокрутите вниз и выберите **«На экран "Домой"»** (Add to Home Screen).
4. Нажмите **«Добавить»**. Приложение появится на рабочем столе как нативное iOS-приложение без рамок браузера.
